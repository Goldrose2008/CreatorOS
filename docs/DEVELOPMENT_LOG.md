Vite пытался отслеживать файлы Rust внутри `src-tauri/target`, из-за чего Windows возвращала ошибку `EBUSY`.

```
src-tauri
```
После этого CreatorOS успешно запустился.

##### Возникшая проблема:
```
No sql driver enabled.
Please set at least one of the "sqlite", "mysql", "postgres" feature flags.
```
Причина:
Плагин SQL был установлен, но драйвер SQLite не был активирован.
###### Решение:
Выполнено:
```
cargo add tauri-plugin-sql --features sqlite
```
После этого Cargo добавил поддержку SQLite.

##### Возникшие проблемы:
###### Проблема 1
Ошибка:
```
expected one of `.`, `;`, `?`, `}`, or an operator
```
Причина:
Неправильное размещение SQL-плагина внутри `setup()`.
Решение:
Перенесли подключение плагинов в основной Builder.
###### Проблема 2
Ошибка:
```
this method takes 2 arguments but 3 arguments were supplied
```
Причина:
Версия `tauri-plugin-sql 2.4.1` использует другой синтаксис:
Было:
```
add_migrations(
    database,
    kind,
    migrations
)
```
Правильно:
```
add_migrations(
    database,
    migrations
)
```
