# Пользовательский справочник

## 1. Общая информация

Приложение предназначено для управления процессом создания контента: от проекта и планирования до производства, публикации и анализа результата.

Основной объект системы — проект.

Проект объединяет основной контент, дополнительный контент, задачи, публикации, материалы и другие связанные данные.

## 2. Навигация

В левой боковой панели находятся основные разделы:
* Главная
* Проекты
* Задачи
* Планирование
* Библиотека
* Аналитика
* Настройки

## 3. Проекты

Раздел «Проекты» содержит все контентные проекты.

Для каждого проекта доступны:
* просмотр;
* редактирование;
* удаление.

Чтобы открыть проект, можно нажать его название или кнопку «Открыть».

## 4. Страница проекта

На странице проекта отображается основная информация:
* название;
* описание;
* тип проекта;
* статус;
* планируемая дата публикации;
* ответственный;
* дата создания.

Ниже расположены основные рабочие разделы проекта:
* Основной контент;
* Дополнительный контент;
* Задачи.

## 5. Настройки

Настройки разделены на отдельные категории:
* Система;
* Контент;
* Интеграции;
* Дополнительно.

### Внешний вид

В разделе «Внешний вид» можно выбрать основной цвет интерфейса.

Выбранный цвет применяется сразу и сохраняется после перезапуска приложения.
